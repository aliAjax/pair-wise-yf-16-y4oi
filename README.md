# hxyfront-62004 客户接批台 · 滑雪板调校维护

源提示词编号：6

面向滑雪板调校店的装备维护前端系统，已从静态维护列表升级为**客户接批台**。

## 核心业务规则

- **接批**：一次只接同一客户尚未完工（待接批）的雪板，整批入队。
- **整批拒绝**：批次中有底板损伤的雪板必须填写修补位置，否则整批拒绝，队列和原工单不变。
- **偏好版本**：接批后每次修改客户偏好都保留历史版本。
- **退回待复检**：偏好变更后，该客户所有未完工雪板自动退回待复检，已完成记录不改。
- **完工门禁**：复检确认前不能完工；复检确认后工单恢复原状态。
- **同步**：完工筛选、刃角参数表、底板损伤标记、客户历史共用同一数据仓库，实时联动。
- **持久化**：全部数据写入浏览器 localStorage（键：`hxyfront-62004:shop:v1`），刷新不丢；首页可一键重置演示数据。

## 页面结构

- 指标卡：待维护 / 完工工单 / 平均刃角 / 底板修补
- 客户接批台：选客户 → 勾选待接批雪板 → 校验接批；批次队列
- 工单队列：完工状态筛选（全部/待接批/维护中/待复检/已完工），复检确认与完工操作
- 客户偏好：版本化编辑，保存即触发退回待复检
- 新建工单：品牌、长度、板型、刃角、打蜡、底板损伤登记
- 刃角参数表：侧刃/底刃/打蜡在线调整（已完工锁定）
- 底板损伤标记区：损伤开关 + 修补位置增删
- 客户历史：偏好版本、接批批次、工单记录
