# hxyfront-62004 滑雪板调校维护 · 客户接批台

面向滑雪板调校店的装备维护前端系统，在维护列表基础上升级为「客户接批台」。

## 业务规则

- **一次一批一客户**：接批台一次只接同一客户尚未完工的雪板（待接批 → 施工中）；本批全部完工自动收台后，才能接待下一位客户。
- **损伤强制修补位置**：批次内任一雪板有底板损伤但未填写修补位置，整批拒绝；拒绝为原子操作，队列与原工单均不改变。技师可先在队列工单的底板图上补齐修补位置再重新接批。
- **客户偏好版本化**：接批后每次修改客户偏好都生成并保留新版本（蜡型 / 咬雪 / 说明 / 时间），历史版本可回溯。
- **偏好变更退回复检**：保存新偏好时，该客户所有未完工雪板退回「待复检」（已完成记录不改）；复检确认前不能完工，支持单板确认与整批确认。
- **完工冻结**：完工记录保存偏好版本快照与完工时间，之后不再随偏好变更修改。
- **数据本地存储**：工单、客户、偏好版本与完工记录全部写入浏览器 `localStorage`，刷新不丢失；可一键恢复示例数据。

## 页面模块

- 接批台：按客户分组的待接批队列、损伤校验提示、偏好版本编辑器、批次雪板卡片
- 刃角参数表：侧刃 / 底刃统一编辑（仅施工中可改），与工单卡片实时同步
- 底板损伤标记区：雪板底板示意图 + 板头 / 固定器区 / 板腰 / 板尾六分区点选
- 完工状态筛选：全部 / 待接批 / 施工中 / 待复检 / 已完工，叠加板型筛选
- 客户历史维护记录：偏好版本时间线 + 完工工单快照

## 技术栈

React 19 + Vite + TypeScript，纯前端、无后端依赖。
